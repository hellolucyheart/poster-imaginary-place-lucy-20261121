LUMINARA — a travel poster for a place that isn't there: a chain of isles drifting above a sea of cloud, where the sun never quite sets. A self-contained Python program (standard library only, no network, no external assets) paints the poster and writes it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

The program draws the poster entirely in code — a posterised sunset sky, a low sun, floating isles with a lantern tower and a waterfall spilling into the cloud sea — and the place name LUMINARA set in bold stroke lettering. It is fully deterministic: two runs produce byte-identical output (1024×1024 PNG, well under the 1 MiB limit).

## About the poster

LUMINARA is an invented place: no real destination, no borrowed artwork. The one landmark is the lantern tower of the main isle, whose lamp burns gold over the cloud sea while a waterfall spills off the isle's edge and vanishes into the mist below.
